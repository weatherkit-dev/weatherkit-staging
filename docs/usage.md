# Usage

## current

    weatherkit current <city> [--units metric|imperial]

Prints the current temperature and condition for a city.

## forecast

    weatherkit forecast <city> [--days N] [--units metric|imperial]

Prints the daily maximum for the next N days (1 to 7, default 3).

## alerts

    weatherkit alerts <city>

Lists the active weather alerts for a city, with their severity.
